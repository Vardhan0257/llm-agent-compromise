AgentCompromiseLab — Short Report

Overview
--------
This repository contains a compact red-team simulation for autonomous LLM agents. The code exercises a pipeline from user prompt to context ingestion to tool invocation, and includes prototype mitigations and experiment harnesses.

What I implemented (summary)
----------------------------
- Pluggable validator (`tools/validator.py`) that uses scikit-learn if available, else a conservative heuristic.
- Integrated validator into `SecurityMonitor` to perform a reasoning sanity check before tool invocation.
- Structured experiment scripts:
  - `scripts/run_controlled_experiments.py` (deterministic, seeded; compares baseline vs validator)
  - `scripts/run_experiments.py` (simple randomized runner)
- Sample `results/metrics.csv` and deterministic `results/controlled_metrics.csv` (generated by running the scripts).
- Basic unit tests and CI workflow.
- README updates with pipeline diagrams and an interview-friendly summary.

Recommended next steps
----------------------
1. Run `scripts/run_controlled_experiments.py` locally and compute detection/compromise rates per mode.
2. Create a short notebook `notebooks/experiment.ipynb` to plot ROC/precision-recall charts and show before/after comparisons.

Ethics & safe use
-----------------
This project is research-only. Keep experiments offline and simulated. Do not use assets or payloads against real systems or people.
